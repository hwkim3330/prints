# mikroBUS LED click (printed)

AC164162 의 mikroBUS 소켓에 꽂아서 Seeed 104990014 RGB LED 띠(WS2812 계열, 60 LED/m, 5 V)를 연결하는 출력 받침. PCB 없음.

- 28.6 × 27.4 × 2.5 mm (Click S 길이, 폭은 핀헤더 홈 바깥 벽 1 mm 씩 남기려고 2 mm 넓힘 — 소켓 간격 29.2 라 옆 소켓과 안 닿음), 0.12 mm 층: **12분 / 1.7 g** (`led_click.gcode.3mf`), 8개 한 판 **46분 / 13 g** (`led_click_x8.gcode.3mf`)
- 방향: mikroBUS 표준처럼 **오른쪽 아래 모서리를 45° 깎음** (AN·PWM 이 위, PWM 줄이 오른쪽일 때 GND 끝). 베이스 보드 소켓 실크 외곽선의 깎인 모서리와 맞춰 꽂는다. 글자는 너무 작아 안 새김.
- 1×8 수 핀헤더 2개를 홈에 끼운다(플라스틱 몸통이 판 안, 긴 핀이 아래로 소켓에). 끝의 1×3 핀헤더에 LED 띠를 꽂는다.
- 윗면에서 피복 전선 3가닥을 납땜: **PWM → DI(가운데), 5V → 5V, GND → G** (모두 PWM 쪽 줄, 위에서부터 PWM 1번 … 5V 7번, GND 8번). 1×3 은 깎인 모서리 쪽이 G.
- 데이터선에 330 Ω, 띠 쪽 5 V–GND 에 470–1000 µF. 60개 전부 흰색이면 ~3.6 A — 베이스의 5 V 핀으로는 못 준다: 밝기를 낮추거나 띠 5 V 를 따로 준다.
- 소스: `led_click.py` (cadquery)
