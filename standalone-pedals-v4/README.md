# Pedals V4 · 낮은 한 장 베이스

246 × 245 mm의 A1용 PETG 공용 베이스. 두 페달 힌지와 스토퍼를 바닥판에 직접 두고 양쪽 가장자리와 중앙에 보강 리브를 뒀다. 발판 아래의 긴 기둥은 제거했다. 베이스에는 M6 고정점이 있고 강성이 있는 리그 판에 관통 체결한다.

- `A1-ribbed-base.stl` / `Pedal-V4-One-Piece-Base-PETG.gcode.3mf`: 상·하판 대신 한 판으로 출력하는 공용 베이스다.
- `MG996R-upright-x2.stl`: MG996R 두 개를 발끝 쪽에 세워 붙이는 별도 플레이트다. 바닥에 눕혀 2개 출력한다. 금속 ㄱ자 브래킷과 M5 관통 볼트로 베이스에 체결한다. 서보 장착 피치는 명목 49.5 × 10 mm이며 기존 맞춤 쿠폰으로 확인한다.
- `6-arm-direct-drum-x2.stl`: 기존 1번 윤곽의 6발 혼이 드럼 밑면에 직접 들어가는 일체형 시제품이다. 순정 중앙 나사 접근 홀을 유지했다. 혼의 중간 홀 반경이 9 mm라면 120° 간격으로 세 곳에서 M2 금속 나사를 혼 뒤에서 플라스틱 파일럿에 체결할 수 있다. 맞지 않으면 `PITCH_RADIUS`를 수정한다. 짧은 금속 나사를 써서 바닥을 뚫지 않게 한다. 이 드럼의 인쇄 방향은 포켓 위이며 플랜지 돌출부는 Bambu Studio에서 서포트를 검토한다.

페달, 힌지, 센서 포스트는 [독립형 모델](../standalone-pedals/)을 사용한다. 각 페달에 Ø8 강철 축, 금속 트레드, 강철 고무범퍼 스토퍼와 복귀 스프링이 필요하다. 스토퍼 볼트는 강성 있는 리그 판까지 관통시킨다. 한 판이라는 말은 공용 베이스에 해당한다. 회전하는 부품은 따로 조립한다.

공용 베이스와 캐리어는 CAD 유효 솔리드, 드럼은 폐합 메시를 확인했다. 드럼의 9 mm 홀 위치, 금속 앵글의 치수, 와이어 외피의 고정과 꺾임, 드럼에 부하를 걸었을 때의 나사 유지력, 전체 발 하중은 실물 확인 전이다. 직접 결합 드럼은 무부하부터 시험한다.
