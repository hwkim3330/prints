# SimPedals 액셀 · PETG 통짜 출력

CNCDan/dmcke5의 [SimPedals a5598be](https://github.com/dmcke5/SimPedals/tree/a5598be66d77a0f93598e20f3e6c94437ad59957),
CERN-OHL-S-2.0. 원본 소스 위치는 위 링크의 `Printed Components/Fully Printed Throttle Pedal.STL`이다.
이 출력용 사본은 원본 형상을 Y축 +90°로 회전하고 바닥을 Z=0으로 옮겼다.
라이선스는 같은 폴더에 포함했다.

- 통짜인 것은 액셀 발판과 발판 장착부다. 원본의 측판·축·베어링·복귀부는 별도다.
- 베드 방향 두 가지를 비교했다. 아래쪽 평면 접촉은 약 3,089 mm² 대 345 mm²였다.
- A1 0.4 mm, Generic PETG, 0.20 mm, 벽 6겹, 상하 5겹, 자이로이드 35%. 베드에서 올라오는 서포트를 사용한다.
- 예상 2시간 53분, 53.94 g(서포트 포함). 슬라이서에서 베드 안에 들어갔다. 출력·하중 시험은 미실시.
- 브레이크는 원본 금속 발판과 측판을 먼저 쓴다. 이 출력판은 액셀 발판 하나이며 서보·와이어를 포함하지 않는다.
