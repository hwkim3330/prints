# PETG 두 페달 · 무나사 조립 시제품

244 × 212 mm 베이스 한 장에 축 지지대 3곳과 스토퍼를 통합했다. 브레이크 88 mm, 가속 76 mm. 두 발판은 하나의 Ø16 × 232 mm PETG 축 위에서 각각 움직인다. 금속 나사나 베어링 없이 손으로 조립한다.

1. `00-bore-coupon.stl`과 `00-shaft-coupon.stl`을 먼저 출력해 밀어 넣고 돌려 본다. 짧은 축의 홈에 클립도 시험한다.
2. 베이스와 발판을 배치된 방향으로 출력한다. 축은 STL의 평면을 베드에 댄다. A1에서 각 STL은 치수상 베드에 들어간다. 베이스 폭이 244 mm이므로 실제 슬라이서에서 브림과 시작 구역을 확인한다. 16 mm 가로 홀의 천장은 서포트 또는 출력 후 정리가 필요할 수 있다.
3. 넓은 발판은 왼쪽에 얇은 링 두 개, 좁은 발판은 오른쪽에 두꺼운 링 두 개를 끼운다. 축을 옆에서 밀어 지지대 세 곳과 발판·링을 모두 관통한다. 양 끝 홈에 클립을 끼운다. 전체 부품은 베이스 1, 발판 2, 축 1, 클립 2, 링 4개다.
4. 축 방향 흔들림과 걸림을 손으로 확인한다. 클립을 비틀어 억지로 장착하지 않는다.

CadQuery에서 모든 STL을 유효 솔리드로 확인하고, 두 발판 각각 7~13°의 7개 위치에서 베이스와 간섭이 없는지 검사했다. 끝단 스토퍼 실제 각도, PETG 끼움, 층 방향에 따른 내구성과 발 하중은 실물에서 확인해야 한다. 이 모델은 손으로 조립과 회전을 확인하는 용도다. 복귀 스프링, 센서, MG996R 구동은 포함하지 않는다.

`assembly.step`에는 베이스·축·두 발판을 담았다. CadQuery로 `python model.py`를 실행하면 STL과 STEP을 재생성한다.
